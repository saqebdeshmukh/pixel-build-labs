# Studio Forge

Build a premium, modern, highly polished website for a software consulting and engineering firm.

The company provides end-to-end software solutions, including:

Custom web application development

Mobile application development

AI agents and AI-powered applications

AI workflow automation

Business process automation

API and third-party integrations

Cloud/backend engineering

Legacy application modernization

Custom software consulting

The website should communicate:

“We don't just advise businesses. We design, build, automate, and ship software.”

The overall positioning should feel like a modern software engineering studio + AI automation consultancy, not a traditional IT outsourcing company.

1. DESIGN DIRECTION

Create a premium B2B technology website inspired by the visual quality of modern companies such as Linear, Vercel, Stripe, Raycast, and contemporary AI product studios.

Do NOT copy their designs. Use them only as inspiration for quality, spacing, typography, interactions, and visual sophistication.

The design should be:

Modern

Minimal

Premium

Technical

Trustworthy

Sophisticated

Clean

Slightly futuristic

Professional enough for enterprise clients

Approachable enough for startups and small businesses

Avoid:

Generic corporate website layouts

Excessive blue gradients

Stock photography

Cheesy business illustrations

Generic handshake/team images

Excessive glassmorphism

Excessive animations

Huge amounts of text

Overly colorful UI

Template-looking sections

The website should feel like it was designed by a high-end product design agency.

2. COLOR SYSTEM

Use a subtle modern color palette.

Primary background:
Very dark charcoal / near-black, approximately #0B0D10.

Secondary dark surface:
#111419

Card background:
#151920

Primary text:
#F5F7FA

Secondary text:
#9AA3B2

Borders:
Subtle #242A33

Primary accent:
Use a sophisticated electric indigo / violet such as #7C6CFF.

Secondary accent:
Very subtle cyan/blue such as #5AC8FA.

Use gradients extremely carefully.

For example, subtle indigo-to-cyan glow can be used behind hero elements, but it should never overpower the content.

Provide a light/dark design system only if it can be implemented elegantly. Dark mode should be the primary experience.
